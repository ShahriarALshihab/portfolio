# Personal Portfolio

A modern personal portfolio website built with **Astro**. It showcases my skills, projects, experience, and technical journey, along with a personal blog.

## 🚀 Tech Stack

- Astro
- TypeScript
- HTML & CSS
- Markdown
- JavaScript
